This project is developed for learning purposes, inspired by early UNIX-like systems

### Current Status (ALPHA)

**-LambdaShell 0.1:** A custom-built command-line interface.

**-PS/2 Keyboard Driver:** Full interrupt-driven keyboard support.

**-CMOS Integration:** Real-time clock access for system time.

**-GDT/IDT/ISR/IRQ:** Robust interrupt handling and segmentation logic.

**-Timer Support:** Programmable Interval Timer (PIT) for system ticks.

### 🛠 Technical Updates:**

**-Optimized Makefile for sysroot-based cross-compilation.**

**-Implemented basic string manipulation library (libk).**
